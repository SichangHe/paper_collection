3.2 Verification of ACSL Specifications Using Frama-C
Frama-C [1] is an open-source platform for static analysis and
formal verification of C programs. Its modular architecture
enables various plug-ins to operate collaboratively. Among
these, the WP (Weakest Precondition) plug-in [30] serves as
the core tool for deductive program verification. WP uses a
Hoare logic weakest-precondition calculus to generate verifica-
tion conditions (VCs) that capture the correctness of the code
with respect to the specifications. In essence, WP computes
logical conditions that must hold for the code to satisfy all its
ACSL annotations. These conditions are then discharged by
automated theorem provers (SMT solvers such as Alt-Ergo
or Z3) or sent to interactive proof assistants (e.g. Coq) to
