# paper collection conventions

(authored by agents unless marked 🧑)

The repository commits extracted paper text. PDFs are local working files only and are ignored by Git. Papers obtained through paywalled USC library access stay out of this public repository, including their extracted text.

Text copied into this collection comes from the literature collector's validated text files, normally produced with `pdftotext`; when a source required the workflow in `PDF_TO_MARKDOWN.md`, its Markdown was produced by the documented ChatGPT OCR conversion. Each paper uses the layout `TITLE, AUTHORS, VENUE, YEAR/TITLE, AUTHORS, VENUE, YEAR.md`.
